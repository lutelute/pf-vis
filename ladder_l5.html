連続潮流とPV曲線 — 解が消える点を追跡する

L0の「送電の限界」、L2の「sinδの頂上」、入門ツールの「電圧崩壊直前」——ラダーの各段で 予告してきた限界を、ここで正面から扱います。負荷を増やしながら潮流解を追跡すると、 解は2つ→1つ→ゼロと減っていき、消える瞬間の点（ノーズ）ではヤコビアンが特異になる。 この曲線の実トレースが、電圧安定性解析の出発点連続潮流（Continuation Power Flow）です。 このページの曲線は全点が実計算です。
なぜ学ぶ?系統がどこまで負荷に耐えるか（電圧安定性余裕）を測る実務・研究の標準手法だから。
一言で言うと負荷倍率λを連続的に変えて解の曲線を描く。曲線の折り返し点（ノーズ）＝解が消滅する点＝det J = 0。
L4との接続「NRがノーズ付近で苦しむ」のは偶然ではない——解くべき方程式のヤコビアンそのものが特異に向かうから。
F(x, λ) = 0,　x = (V, δ),　負荷 = λ·(P₀, Q₀)　　［ノーズ: det J(x*) = 0］ 読み：λ（ラムダ）は負荷の倍率。λを増やしながら解xの道を追う。折り返し点ではヤコビアンJの行列式がゼロになり、 λを媒介変数にした追跡は破綻する——そこで歩く向きを変える（本ページはVを媒介変数にして曲線全体を描いている。 弧長を使う一般版がpredictor-corrector型の連続潮流）。

実験: PV曲線を実トレースする

負荷の性質:

上の曲線: PV曲線（実線=上枝・破線=下枝・▼=ノーズ）。下の帯: 上枝に沿った |det J|（実計算）——ノーズでゼロに落ちる。

この実験からわかる4つのこと

1同じ負荷に、解が2つある。 曲線の上枝と下枝——例えば200 MWの負荷に対し、高い電圧の解と低い電圧の解が両方とも方程式を満たします。 実際に運転できるのは上枝だけ（下枝は電流が過大で、制御をかけると不安定化する）。 「解けた」だけでは足りず、どちらの解かを問うのがこのレベルです。
2ノーズで det J = 0（実測できる）。 下の帯を見てください。負荷を増やすほど |det J| が減り、ノーズでゼロに触れる—— 2つの解が接近・合体して消える瞬間、ヤコビアンは特異になります。 L4で「NRは崩壊の縁で苦しむ」と観察した現象の、これが理論的正体です。
3無効電力補償はノーズを伸ばす——が、話には裏がある。 「補償あり」に切り替えると、ノーズは446 MW→690 MWへ大きく伸びます（コンデンサでQを地産地消した効果）。 しかしノーズ電圧も 0.55→0.67 へ上がることに注目——補償の効いた系統は、 普段と大差ない電圧のまま崩壊点に接近できてしまう。電圧の低さを崩壊の警報として使えなくなる、 という実務上の重要な逆説です。
4この折り返しには数学の名前がある。 パラメータを動かすと2つの解が合体して消える——力学系理論のサドルノード分岐（saddle-node bifurcation）です。 電圧崩壊の解析が分岐理論・特異点理論と接続するのはこのため。L6で研究の言葉として再訪します。
⚠ 正直な注意 — 静的PV曲線の限界
①実系統では発電機の無効電力上限により、滑らかなノーズの手前で曲線が折れて突然余裕を失うことがある （limit-induced bifurcation。ノーズだけ見ていると危険側に誤る）。 ②このPV曲線は静的解析であり、OLTC（タップ切替）や誘導電動機の動特性が絡む実際の電圧崩壊の 時間発展は語れない（動的解析・時間シミュレーションの領分）。 ③実務ではPV曲線に加えQV曲線・モーダル解析（Jの固有値）を併用する。
