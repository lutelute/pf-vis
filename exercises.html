Q3-2. Fast Decoupled 法の分離根拠を数値で確認★★☆🖥ツール💭考察

NR実行中の「ブロック平均|要素|」（∂P/∂δ, ∂P/∂V, ∂Q/∂δ, ∂Q/∂V の4つ）を記録し、 「対角ブロックが非対角ブロックより大きい」ことを確かめよ。これがFast Decoupled法の何を正当化するか説明せよ。

解答と解説
送電系統では x≫r のため、∂P/∂δ と ∂Q/∂V（対角ブロック）が ∂P/∂V と ∂Q/∂δ（非対角）より数倍〜十倍大きい。 つまり「Pはほぼδだけで、QはほぼVだけで決まる」— そこで非対角ブロックを丸ごと0とみなし、 P-δ問題とQ-V問題を別々の小さな連立方程式として解くのがFast Decoupled法。 1反復の計算量が減る代わりに反復回数は増える（このサイトの実装ではNR 4回に対しFDXBは8〜22回）が、 B′/B″が定数行列でLU分解を使い回せるため大規模系統では総合的に速くなる。

Stage 4 — 比較: 収束の質を測る

使用ツール: アルゴリズム同時比較（IEEE 9-bus）

Q4-1. Gauss-Seidel を収束させる★★☆🖥ツール

NR・FDXB・GS を選択し、既定の最大反復数（50）で同時実行すると GS は「上限到達(未収束)」になる。 (a) これは発散とどう違うか。(b) 最大反復数を 300 に上げて再実行し、GSが収束するまでの反復数を記録せよ。 (c) 「真の解への距離」チャートで、GSの線はどんな形か。それは何収束の証拠か。

解答と解説
(a) 発散は誤差が増え続けて破綻すること。上限到達は収束の途中で打ち切られただけで、 反復を続ければ解に到達する。(b) おおよそ190回前後で収束する（許容誤差 10⁻⁶ の場合）。
(c) 片対数グラフ上でほぼ直線。誤差が反復ごとに一定比率で減る = e_{k+1} ≈ ρ·e_k（0<ρ<1）、 これが線形収束（1次収束）の定義そのもの。NRの「崖」（2次収束）との違いが一目で分かる。

Q4-2. 収束次数を自分で推定する★★★🖥ツール✋手計算

NRの誤差履歴（各反復の最大ミスマッチ）を3点以上記録し、e_{k+1} と e_k² の比がほぼ一定になることを確かめよ （2次収束の判定）。GSでは e_{k+1}/e_k がほぼ一定になることを確かめよ（線形収束の判定）。

ヒント
Stage 1 の 2ノード例なら NR は e = 2.5 → 1.6×10⁻¹ → 8.1×10⁻⁴ → 2.3×10⁻⁸。 e₂/e₁² = 0.16/6.3 ≈ 0.025、e₃/e₂² = 8.1e-4/2.6e-2 ≈ 0.031 — ほぼ一定。
さらにヒント（実は自動でも見られる）
compareの結果カードに「実測収束次数 p」が表示される。まず自分で e の比を計算してから、 表示値（p = ln(e_{k+1}/e_k)/ln(e_k/e_{k-1}) の推定）と突き合わせると理解が定着する。
解答と解説
2次収束: e_{k+1} ≈ C·e_k²（Cはほぼ一定）→ 誤差の指数が反復ごとに倍になる。
線形収束: e_{k+1} ≈ ρ·e_k → 指数が一定幅ずつしか減らない。
「あと3桁精度を上げたい」とき、NRなら+1反復、GSなら数十反復必要になる — 収束次数の実務的な意味はこれ。

Stage 6 — 応用: 近似の限界を定量化する

Q6-1. DC近似はどこまで使えるか★★☆🖥ツール💭考察

解答と解説

使ってはいけない場面: 電圧・無効電力が問題になる解析（電圧安定性、調相設備の計画）、 損失が効く精算、R/X比の大きい配電系統。DCはこれらの情報を原理的に持っていない。

Q6-2. 総合問題: 手法選択★★★💭考察

次の3つの業務にNR / Gauss-Seidel / DC のどれを使うべきか、収束次数・計算量・得られる情報の観点から選び、理由を述べよ: ① 系統計画で1万ケースの概略潮流を流す、② 电圧も含めた日常の系統解析、③ 教育目的で反復法の仕組みを一歩ずつ見せる。

解答と解説
① DC — 反復なしの線形解で桁違いに速く、概略のP配分には十分。
② NR — 2次収束で4〜6反復、V・Q・損失まで全て得られる。実務の標準。
③ Gauss-Seidel — 1母線ずつの更新で「反復で解へ近づく」過程が最も見えやすい。 遅い（IEEE14で百数十回）こと自体が、NRのありがたみを教えてくれる教材になる。

Stage 7 — 総合チャレンジ

学んだ全てを使う開放型課題。決まった一つの正解はなく、自分で検証まで行う。

Q7-1. 自分の2母線問題を設計して解く★★★✋手計算💭考察

自分で線路定数（r, x）と負荷（P, Q）を1組決め、Stage 2と同じ手順を最初から最後まで通せ: ① Ybus構築 → ② フラットスタートのヤコビアン → ③ NR 1反復 → ④ DC解との比較。

答え合わせの代わりに、次の自己検証基準を満たすことを確認せよ:

  1. Ybusの対角虚部が負（誘導性）になっている
  2. 1反復後のミスマッチが初期値より小さくなっている（NRが機能している証拠）
  3. 負荷母線の δ が負（角度が遅れる）、|V| が1.0未満になっている
  4. DC解 δ = −P·x が AC解の δ と同符号・同程度になっている
ヒント
x/r 比は3〜5程度（送電線らしい値）、負荷は P=0.3〜0.8 p.u. 程度にすると計算しやすい。 重すぎる負荷（P>2 p.u.など）を選ぶと解が存在しないこともある — それ自体がStage 1で学んだ電圧崩壊。
さらにヒント（計算が楽になる選び方）
z = 0.03 + j0.09 を選ぶと |z|² = 0.009 で y = (0.03 − j0.09)/0.009 = 3.33 − j10 と切りが良い。 フラットスタートなら P_calc = Q_calc = 0 になるので、ヤコビアンは [[−V²B, VG], [−V²G, −VB]] = [[10, 3.33], [−3.33, 10]] の形で即書ける。
解説（設計の見方）
この課題の狙いは「答えを当てる」ことではなく、解の妥当性を自分で判定する力。 実務でも真の解は誰も教えてくれない — 収支・符号・大きさのオーダー・別手法との一致という 検証基準で解を信頼するしかない。基準1〜4はそのミニチュア版になっている。

Q7-2. 電圧崩壊の縁で手法を比べる★★★🖥ツール💭考察

収束過程直感的理解の 「2ノード(電圧崩壊直前)」で NR法・Gauss-Seidel法・勾配降下法をそれぞれ実行し、 (a) 反復数と最終誤差を記録、(b) 複素平面での軌跡の違いを言葉で描写、 (c) この運転状態でDC潮流を使うと何を見落とすかを述べよ。

解答と解説
(a)(b) 崩壊直前では解が「解の存在領域」の縁にあり、NRでもステップが暴れやすく バックトラッキングが働く（反復数が増える）。GSはさらに苦しく、進みが極端に遅くなる。
(c) DCは |V|=1.0 を仮定するため、電圧が崩れかけていること自体を検出できない。 位相角の概算は出るが、電圧安定性の危険を完全に見落とす — 「DCを電圧問題に使ってはいけない」 （Q6-1）の最も極端な実例。
