# power_flow_v5.html — 統合分析スイート

## 概要

基本4手法に発展的手法を加えた**8つの潮流計算アルゴリズム**を、同一系統・同一条件で
同時実行して比較する分析ツールです。学習パスの「発展」段階に位置づけられます。

すべての手法はページ内に実装された本物の数値計算です（疑似データやシミュレーションではありません）。

## 学習目標

- 基本手法（NR / FD / GS / DC）と発展手法（減衰・緩和系）の関係を理解する
- 同じ問題に対する収束次数・反復回数・頑健性のトレードオフを実感する
- 「上限到達（未収束）」と「発散」の違いを区別できるようになる

## 実装アルゴリズム（8手法）

| キー | 手法 | 更新式の要点 | 収束 |
|---|---|---|---|
| nr | Newton-Raphson | J·Δx = [ΔP; ΔQ] | 2次 |
| fdxb | Fast Decoupled XB | B′Δθ = ΔP/\|V\| → B″Δ\|V\| = ΔQ/\|V\| | 線形(高速) |
| fdbx | Fast Decoupled BX | Q-V更新 → P-θ更新（XBの逆順） | 線形(高速) |
| gs | Gauss-Seidel | V_i ← (1/Y_ii)[S_i*/V_i* − ΣY_ij V_j]（逐次） | 線形 |
| gj | Gauss-Jacobi | 同上（一斉更新・並列化可能） | 線形（GSより遅い） |
| dc | DC潮流 | B θ = P（線形・反復なし） | 直接 |
| lm | Levenberg-Marquardt | (JᵀJ + μI)Δx = Jᵀf（μ=0.01固定） | 超線形 |
| rnr | Relaxed Newton | NRの更新量に α=0.8 を乗じる | 2次（減速） |

実装上の注意:

- **B′行列**は直列リアクタンスのみ（1/x）から構築します。シャント・線路充電容量は
  含めません（B″には含めます）。DC潮流のB行列も同様で、タップ比を考慮します
- **GS/GJのPV母線**では、Qは指定値ではなく現在の電圧推定から
  Q_i = Σ_j |V_i||V_j|(G_ij sinθ_ij − B_ij cosθ_ij) として毎回計算します
- **LM**は固定μの簡易版です（本来のLMはμを適応調整します）
- かつて「Holomorphic Embedding (HELM)」と表示していた手法は、実装実態が
  緩和付きNRだったため **Relaxed Newton (RNR)** に改称しました。
  真のHELMは実装していません（理論は `power_flow_methods.md` §6.3 参照）

## 収録系統

IEEE 2 / 5 / 9(WSCC) / 14 / 30 母線系統（MATPOWER v2形式、`scripts/ieee_cases.js` と同一データ）。

## 使い方

1. 系統と比較したい手法（チップ）を選択
2. 収束判定値（既定 1e-6）・最大反復回数を設定
3. 「▶ 実行」で全選択手法を同時実行
4. 収束曲線（片対数）・反復回数チャート・電圧誤差（NR解基準）を比較

### 結果の見方

- **収束**: 許容誤差以内に到達
- **上限到達(未収束)**: 収束途中で反復上限に達した（GS/GJで既定設定のままだと起こりやすい。
  正常な挙動であり、線形収束の遅さを示す教材的な結果）
- **発散**: ミスマッチが発散（数値的破綻）

## 典型的な結果（IEEE 14母線・tol 1e-6）

| 手法 | 反復回数 |
|---|---|
| NR | 4 |
| LM | 5 |
| FDXB / FDBX | 8 |
| RNR | 10 |
| GS | ~170（上限100では未収束） |
| GJ | GSよりさらに遅い |
| DC | 1（直接） |

## 制限事項

- LMのμは固定値（適応制御なし）
- 発電機の無効電力制限（Q limits）は考慮しない
- タップ・移相器は固定値として扱う
