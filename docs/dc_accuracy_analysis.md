# dc_accuracy_analysis.html — DC潮流精度検証

## 概要

DC潮流計算（線形近似）の解を AC潮流解（Newton-Raphson）と比較し、
近似誤差を定量化する分析ツールです。共有計算エンジンを使用します。
学習パスの「応用」段階に位置づけられます。

## 学習目標

- DC近似の仮定（|V|=1、r≪x、小角度）がどの程度成り立つかを実データで確認する
- 位相角誤差・支路潮流誤差の分布を見て、DC潮流の適用限界を判断できるようになる
- 系統条件（負荷レベル、R/X比）によって誤差がどう変わるかを理解する

## 分析内容

1. **AC基準解**: Newton-Raphson法で厳密解を計算
2. **DC解**: B行列（1/(x·τ)構築）による線形直接解
3. **誤差評価**: 母線位相角誤差（平均・最大）、支路有効潮流誤差、
   ランキング表示（誤差の大きい支路）

## 収録系統

IEEE 5 / 9 / 14 / 30 母線（MATPOWER準拠・検証済み）＋ランダム生成系統（30/50/100母線）。

## 典型的な結果の目安

- IEEE標準系統・通常負荷では位相角誤差は平均1度未満
- R/X比が大きい系統（配電系統的な条件）や重負荷時に誤差が拡大する
- DC潮流は電圧・無効電力の情報を一切持たない点に注意

## 使い方

1. 系統と許容誤差を選択
2. 「▶ Run Analysis」でAC/DC両方を計算し、誤差サマリと分布を表示
