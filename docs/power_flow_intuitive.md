# power_flow_intuitive_v6_fixed.html — 収束過程直感的理解

## 概要

潮流計算が「非線形方程式の反復解法」であることを、**複素電圧平面上の収束軌跡**として
視覚的に体感できる入門用ツールです。学習パスの「入門」段階、最初に触るページです。

## 学習目標

- 潮流計算の解が「電力ミスマッチをゼロにする電圧の組」であることを直感的に理解する
- 反復のたびに解へ近づく軌跡を見て、収束・非収束・振動の違いを見分けられるようになる
- 負荷を重くすると解が存在しにくくなる（電圧崩壊に近づく）ことを体験する

## 実装アルゴリズム

| 手法 | 特徴 |
|---|---|
| Newton-Raphson法 | 標準・高速。フルステップ+バックトラッキングで、対数グラフ上に2次収束が現れる（中負荷2ノードで4反復） |
| Gauss-Seidel法 | 線形収束（誤差が反復ごとにほぼ一定比で減少。中負荷2ノードで約24反復） |
| 勾配降下法（数値勾配） | ミスマッチノルムの最小化として解く参考実装 |
| DC潮流法 | 線形近似の1発解。AC解とのずれも確認できる |

## 重要な設計上の注意

このツールは**選択した1母線（注目母線）の電圧 (|V|, δ) だけを未知数**として解く簡約問題を
可視化します。他の母線の電圧は固定値です（だからこそ2次元の複素平面・誤差面で全体を描けます）。
多母線系統の完全な潮流解を求めるには `power_flow_matpower_v2.html` 等を使ってください。
3ノード以上の系統選択肢には「※注目母線のみ求解」と明記しています。

## 問題設定（段階的な難易度）

- 2ノード（軽負荷 → 中負荷 → 重負荷 → 臨界負荷 → 電圧崩壊直前）
- 3ノード（標準 / 不平衡負荷）
- 30ノード（IEEE風の簡略系統・ランダム系統）

負荷を重くするほど解が複素平面の「解の存在領域」の端に近づき、
収束が難しくなる様子を観察できます（PV曲線のノーズに相当する現象）。

## 画面の見方

- **複素電圧平面**: 各反復での電圧の位置。星印が真の解
- **誤差面**: ミスマッチノルムの等高線と現在位置
- **収束曲線**: 反復ごとの誤差 ||ΔS||（片対数）

## 使い方

1. アルゴリズムと問題（負荷レベル）を選択
2. 「▶ 実行」でアニメーション表示、速度スライダで調整
3. 難しい問題ほど反復数が増える・発散することを確認
