# power_flow_compare.html — アルゴリズム同時比較

## 概要

主要な潮流計算アルゴリズム（最大8手法）を**同一系統・同一条件で同時実行**し、
収束特性の違いを並べて理解する比較ツールです。学習パスの「比較」段階に位置づけられます。

各手法の計算過程（初期化 → ミスマッチ計算 → 更新 → 収束判定）が
ステップ表示されるため、手法間の構造の違いも追えます。

## 学習目標

- 2次収束（NR）と線形収束（GS/GJ）の差を収束曲線の傾きで理解する
- 分離近似（FDXB/FDBX）が「1反復は軽いが反復数は増える」ことを確認する
- DC潮流が反復なしで解ける理由（線形化）を理解する

## 実装アルゴリズム

| 手法 | 分類 | 収束 | 備考 |
|---|---|---|---|
| Newton-Raphson (NR) | 基本 | 2次 | 完全ヤコビアンを毎回更新 |
| Fast Decoupled XB | 基本 | 線形(高速) | B′(1/xのみ)・B″(-Im Ybus)は固定 |
| Fast Decoupled BX | 基本 | 線形(高速) | Q-V更新を先に行う変種 |
| Gauss-Seidel (GS) | 基本 | 線形 | 逐次更新。PV母線はQを毎回推定 |
| Gauss-Jacobi (GJ) | 参考 | 線形 | 一斉更新。GSより遅い（教材用） |
| DC潮流 | 基本 | 直接 | B行列は1/(x·τ)から構築 |
| Levenberg-Marquardt | 発展 | 超線形 | (JᵀJ+μI)Δx = Jᵀf、μ=0.01固定 |
| Relaxed Newton (RNR) | 発展 | 2次(減速) | NR更新×0.8。旧表記「HELM」を実態に合わせ改称 |

## 収録系統

IEEE 2 / 5 / 9(WSCC) / 14 / 30 母線系統（MATPOWER v2形式・検証済みデータ）。

## 使い方

1. 系統を選択し、比較する手法にチェック
2. 収束判定値・最大反復回数を設定（既定: 1e-6 / 50）
3. 「▶ 同時実行」で全手法を並行実行
4. 下部の収束曲線比較・反復回数比較で結果を確認

### 結果の見方

- GS/GJが反復上限に達するのは異常ではなく、線形収束の遅さを示す教材的な結果です
  （IEEE 14・tol 1e-6ではGSは収束までに約170回必要）
- 最大反復回数を増やせばGS/GJも同じ解に収束することを確認できます

## 制限事項

- 発電機の無効電力制限（Q limits）は考慮しない
- LMのμは固定値
- 実行時間表示はブラウザ環境に依存するため参考値
