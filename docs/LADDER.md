## 設計原則（全レベル共通・厳守）

1. **稚拙にしない** — 語彙は平易にするが、知的水準は落とさない。幼児語・ひらがなの乱発・
   過剰なキャラクター演出を禁止。読者を「まだ道具を持っていない知的な人」として扱う
2. **実計算の原則はL0でも守る** — たとえ話の裏でも本物の物理式を解く。嘘の数字は一つも使わない
3. **たとえには限界を添える** — アナロジーを使ったら、必ず「このたとえが効かなくなる場所」を明記する
4. **同じ一つの真実を、違う言葉で** — L0の「つくる=つかう+うしなう」は L3の電力収支検算、
   L5の潮流解の存在条件と同じ物理。レベルが上がると言葉が数式に置き換わるだけ、と分かる設計にする
5. **昇級課題** — 各レベル末尾に到達目標を確かめる問い（自動判定）。合格したら次レベルへの導線
6. **デザインの品位を統一** — learn_newton と同じ設計言語（和紙調・明朝見出し・数式に読み下し）。
   レベルで変えるのは前提知識だけで、見た目の真剣さは変えない
7. **登録4面** — index のラダーセクション / README / check_pages / check_numerics（実計算アサート）

### #2（2026-07-25）L1「電圧×電流 — 高圧送電の理由」実装
- `ladder_l1.html`: P=VIと損失=I²Rの2本だけで高圧送電の理由を導く。実計算:
  100MWを6.6kVで送ると損失2296MW=物理的破綻、275kVで1.32%、電圧10倍→損失きっかり1/100。
  全電圧階級の損失を対数棒グラフで同時比較。「正直な注意」(三相・電圧降下と送電電圧の区別・
  電圧階級はコストとの均衡)を明記。昇級課題3問(自動判定)
- L1を⏳→✅。数値回帰33/33・全13ページ合格

### #3（2026-07-25）L2「回る矢印と2つの電力」実装
- `ladder_l2.html`: フェーザ実アニメ（回る矢印と影の波）、瞬時電力 p(t)=v(t)·i(t) の
  実計算波形でP=VIcosφ/Q=VIsinφの正体を見せる（φ=90°で平均ゼロを確認可能）。
  P=(V₁V₂/X)sinδ の実カーブとδ=90°の頂上=送電限界。フェーザの適用範囲
  （定常状態のみ）とQ≠損失の区別を「正直な注意」に明記。昇級課題3問
