# power_flow_process_visualizer_v2.html — 計算過程ステップ表示

## 概要

潮流計算の**1反復の中身**（ミスマッチ計算 → ヤコビアン構築 → 線形方程式求解 →
状態更新 → 収束判定）を、段階的に数値とともに表示する教育特化型ツールです。
学習パスの「基礎」段階に位置づけられます。

## 学習目標

- Newton-Raphson法の6段階（初期化/ミスマッチ/ヤコビアン/求解/更新/判定）を追えるようになる
- ヤコビアン行列の中身（どの要素が大きいか、スパース性）を実数値で見る
- 手法を切り替えたとき、どの段階が変わるか（GSにはヤコビアンがない等）を理解する

## 実装アルゴリズム

| 手法 | 表示される計算過程 |
|---|---|
| Newton-Raphson法 | ミスマッチ → ヤコビアン → LU求解 → Δθ, Δ\|V\|更新 |
| Gauss-Seidel法 | 母線ごとの逐次電圧更新 |
| Fast Decoupled法 | B′/B″による分離update |
| DC潮流計算 | B行列構築 → 直接求解（1ステップ） |
| Gauss法 (Jacobi型) | 一斉電圧更新 |

## 収録系統

3 / 5 / 9 / 14 / 30 ノードの教育用系統（ページ内に0-indexed形式で定義。
9/14/30ノードはIEEE標準系統を基にした簡略版）。

## 使い方

1. アルゴリズムと系統を選択
2. 「▶ 実行」で自動実行、「⏭ ステップ」で1段階ずつ進める
3. 右側のパネルで現在の段階・数値（ミスマッチ、ヤコビアン等）・収束曲線を確認

## 制限事項

- 系統データはページ内定義の簡略版（厳密なMATPOWERデータでの解析は
  `power_flow_matpower_v2.html` を使用）
- PVバスのQ制限は考慮しない
