🧭 道すじ — どの順で進むか

上のツール群を巡る2本の道。標準は「推奨学習パス」、前提知識ゼロから登るなら「学習ラダー」。

🎓 推奨学習パス（標準の道）

🚪 はじめに のあと、上から順に進むと、潮流計算の直感 → アルゴリズムの中身 → 手法比較 → 実務水準の解析、と段階的に理解できます。

  1. 入門 収束過程の直感的理解 — 潮流計算は「非線形方程式の反復解法」。解に近づく様子を複素電圧平面で体感する
  2. 基礎 計算過程ステップ表示 — Newton-Raphson法の1反復（ミスマッチ計算 → ヤコビアン → 修正量）を式と数値で追う
  3. 比較 アルゴリズム同時比較 — NR・Gauss-Seidel・高速分離・DCを同一系統で同時実行し、収束次数の違いを見る
  4. 実践 MATPOWER準拠実装 — 実務標準のMATPOWERデータ形式（bus/gen/branch）で IEEE標準系統を解く
  5. 発展 統合分析スイート — 8手法（LM法・連続潮流・HELM等の発展手法を含む）の性能を横断分析する
  6. 応用 DC潮流の精度検証 — 線形近似（DC潮流）はどこまで正確か。AC解と比較して適用限界を定量化する

🪢 学習ラダー（前提知識ゼロから登る道）

たし算だけの入口（L0）から研究の入口（L6）まで、同じ物理を言葉を変えながら登ります。上の学習パスはL3〜L4に対応します（設計: LADDER.md）。

  1. L0 電気はためられない — つくる・つかう・うしなうの釣り合い — 前提はたし算とかけ算だけ。裏の計算は本物（損失の厳密解・送電限界つき）。昇級課題3問
  2. L1 電圧×電流 — 送電線が50万ボルトを使う理由 — 前提は中学理科のV=IRとP=VI。損失I²Rの実計算で「電圧10倍→損失1/100」を突き止める。昇級課題3問
  3. L2 回る矢印と2つの電力 — 交流の言葉 — 前提は高校の三角関数。フェーザ実アニメと瞬時電力p(t)の実計算でP/Qの正体を掴み、P∝sinδでL3へ橋を架ける。昇級課題3問
  4. 橋 複素数という記法 — 回る矢印を代数にする — L2⇔L3の橋渡し: 矢印⇔複素数の往復・S=V·I*（p(t)平均との検算つき）・p.u.法・Ybusの入口。昇級課題3問
  5. L3〜L4 はじめに → 学習パス1〜6 — 学部基礎〜修士: 潮流計算の本体（上の推奨学習パスがこの段）
  6. L5 連続潮流とPV曲線 — 解が消える点を追跡する — 実PV曲線トレース(上枝・下枝・ノーズ=det J=0の実測)。補償の逆説と安定余裕。昇級課題3問
  7. L6 研究の入口 — 収束の地図と、開いている問い — NR収束領域(basin)の実測地図・σ_min(J)崩落の実験＋研究5軸の文献地図。昇級課題3問でラダー踏破

🎤 講義 — スライドで1本の物語を通して聴く

章立てスライドの講演スタイル教材（ブループリント形式）。数式は全て実数値つき・計算は全てその場の本物です。

  1. 講演1 Newton-Raphson潮流計算 — 解けない方程式を、傾きで解く — 全16枚。ミスマッチの地図 → ヤコビアン導出 → 2次収束の実証 → 検算まで（🎲負荷可変）
  2. 講演2 Gauss-Seidel潮流計算 — 連立を解かずに、1母線ずつ — 全14枚。不動点・線形収束・共役の罠。加速係数ωが逆効果になる実測と、崩壊接近で失速する収束比率ρの実験
  3. 講演3 DC潮流 — 割り切りの技術 — 全13枚。3つの割り切りで一次方程式へ。AC/DC誤差の負荷スイープ実測と「DCに見えないもの」
  4. 講演4 電圧崩壊 — 解が消える瞬間 — 全13枚。2解の接近・合体・消滅をPV曲線の実トレースで。初期値依存のNR実走と補償の逆説
