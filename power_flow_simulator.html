⏵ アルゴリズム・シミュレータ

計算の全記録（トレース）をそのまま再生する — 系統図・複素電圧平面・収束曲線の同期アニメーション

このページは共有計算エンジン（MATPOWER公式解と照合済み）にトレース付き求解 API を追加し、 ソルバーが実際に通った全状態をコマ送り再生します。アニメーションは演出ではなく実際に行われた計算の再生で、 どのコマの数値も本物です。Gauss-Seidel は1母線ずつ、高速分離法はP–θ / Q–V の半反復ずつコマが刻まれます。

系統図 — 電圧の沈みと潮流（このコマの状態から毎回計算）
円の塗り＝電圧の高低（紅く沈む＝1.0より低い／青緑＝高い）、針＝位相角δ、 線上の数字＝有効電力[MW]、破線の流れ＝潮流の向き。二重枠＝スラック、青緑枠＝PV母線。 GS再生中は「いま更新している母線」がリングで光ります（30母線では数値ラベルを省略）。
複素電圧平面 — 解へ収束していく軌跡
各母線の電圧 V=|V|e^(jδ) を点で表示、軌跡（尾）が残ります。 NRは数歩で加速して着地、GSは小刻みな行脚、高速分離法は「角度→大きさ」交互の階段。 手法の個性は式ではなく状態空間の歩き方に現れます。
収束曲線（再生と同期・対数軸）
再生中のコマまでの実測値だけが描かれます。サブ反復中の誤差は反復末に更新。
4手法・同時再生 — 同じ系統・同じ初期値・同じ収束判定（1e-6）
1コマ＝1反復で全手法が同時に進み、収束した手法はその場で停止 — NRが終わった後もGSが回り続ける時間の長さが、収束次数の差の体感です。 DCは反復しない別の問題（損失ゼロの線形系統）を解くため誤差競争には参加しません。
誤差の競争（再生と同期・対数軸）
全4手法 × 全5系統 — この場で一斉に解いて実測する
セルは「反復回数 · 実測ms · 実測収束次数p」。セルをクリックするとその手法×系統がモード①で開きます。 最下行のNR総損失は電力収支（発電=負荷+損失）を通った値で、IEEE14の 13.393 MW / WSCC9 の 4.641 MW は MATPOWER公式値と一致します。
同じ方程式・同じ答えでも、そこへ向かう「歩き方」はこれほど違う。 このページの動きはすべて共有エンジンのトレース（solveWithTrace）の再生であり、 可視化のための計算再実装は1行もない — だから見えているものは、計算そのものである。
