はじめに

潮流計算をはじめて学ぶ人のための入口 — 前提知識・用語・最初の5分

潮流計算とは何をする計算か

電力系統では、発電所で作った電力が送電線を通って負荷（工場・家庭）へ流れます。 潮流計算（Power Flow / Load Flow）は、 「各発電機の出力と各負荷の消費が与えられたとき、系統の隅々で電圧がいくらになり、どの線路に何MW流れるか」 を求める計算です。系統運用・設備計画・安定性解析など、電力系統のほぼすべての解析の出発点になります。

入力（わかっていること） 出力（計算で求めるもの） ──────────────────────── ──────────────────────── ・系統の構成（母線と線路のつながり） ・各母線の電圧の大きさ |V| ・線路の定数（r, x, 充電容量） ・各母線の電圧の位相角 δ ・各負荷の消費電力 (P, Q) ・各線路を流れる電力 P, Q ・各発電機の出力 P と電圧設定値 ・送電損失、スラック母線の発電量

難しさの正体はただ一つ: 電力と電圧の関係が非線形（三角関数と積を含む）なので、 連立一次方程式のように一発では解けず、反復法（少しずつ答えに近づく方法）が必要になることです。 このサイトの全ツールは、その「近づいていく過程」を見えるようにしています。

前提知識 — これだけあれば始められます

  • 複素数の基本: a + jb、絶対値と偏角、共役。電圧・電流・電力を複素数で表します（電気工学では虚数単位に j を使います）
  • 交流回路の基礎: オームの法則、インピーダンス z = r + jx、有効電力P[W]と無効電力Q[var]の区別
  • 行列の基本: 行列×ベクトル、連立一次方程式を解くという操作（解き方自体はツールがやります）

微分（偏微分）はStage 2以降で登場しますが、「傾き＝入力を少し変えたとき出力がどれだけ変わるか」という理解で十分です。

最初の5分 — クイックスタート

  1. 収束過程直感的理解 を開く（別タブ推奨）
  2. そのまま「▶ 実行」を押す（Newton-Raphson法・2ノード中負荷が選ばれています）
  3. 左の複素平面で、点が星印（解）へ吸い込まれる動きを見る — これが「反復法が解に収束する」ということ
  4. 右のログで誤差の数字を見る: 2.5 → 0.16 → 0.0008 → 0.00000002。減り方が加速している（＝2次収束）
  5. 問題を「重負荷」に変えてもう一度実行 — 解が変わり、収束が少し苦しくなるのを確認

ここまで確認できたら、準備完了です。学習パスに沿って進んでください。

用語と記号の早見表

用語 / 記号意味
母線（バス, bus）発電機・負荷・線路が接続される「節点」。系統図の丸
p.u.（単位法）基準値（本サイトは100 MVA）に対する倍率で表す無次元表示。P=0.5 p.u.=50 MW
|V|, δ母線電圧の大きさ（p.u.）と位相角。この2つ×母線数が求めたい未知数
P, Q有効電力（実際に仕事をする電力）と無効電力（電圧維持に関わる電力）
Slack母線基準母線。|V|とδ(=0°)を固定し、系統全体の過不足＋損失を発電で引き受ける
PV母線発電機母線。PとVを指定し、Qとδを計算で求める
PQ母線負荷母線。PとQを指定し、|V|とδを計算で求める。最も数が多い
Ybus (G + jB)アドミタンス行列。系統の「つながり方と電気的距離」を1つの行列にしたもの
ミスマッチ (ΔP, ΔQ)指定値 − 現在の解での計算値。これを全母線でゼロに追い込むのが潮流計算
ヤコビアン J感度の行列。「δやVを少し動かすとPやQがどれだけ変わるか」の表
収束 / 発散反復で誤差が許容値以下になる / 誤差が増え続けて破綻する
2次収束 / 線形収束誤差の桁が反復ごとに倍々で減る（NR法）/ 一定幅ずつしか減らない（GS法）
フラットスタート全母線 V=1.0, δ=0 から反復を始める標準的な初期値
MATPOWER電力系統解析の標準オープンソース（MATLAB）。本サイトはそのデータ形式に準拠し、解を照合済み

よくあるつまずき

  • 「ΔPが負ってどういうこと?」 — ΔP = 指定値 − 計算値。負なら「今の電圧の当たりでは電力が余っている」= 角度や電圧を下げる方向に修正される、というだけ。符号に深い意味を求めすぎない
  • 「GSが収束しないんだけど壊れてる?」 — 壊れていません。GSは線形収束なので既定の反復上限では足りないことが多い。「上限到達(未収束)」は発散とは別物 — 最大反復数を増やせば届く（compareで実験できます）
  • 「p.u.とMWどっちを見ればいい?」 — 計算はp.u.、直感はMW。本サイトは両方併記しているので、「0.18 p.u. = 18 MW」の換算（×100）に慣れるのが早道
  • 「ヤコビアンの数字が大きい/小さいのは良いこと?」 — 善悪ではなく感度。対角が大きい=その母線が「堅い」。0が多い=接続がない（スパース性）。まず計算過程ステップ表示でセルをクリックして意味を掴む

このサイトの学び方

  • 順番に進む: メインページの学習パス（入門→基礎→比較→実践→発展→応用）は、前の段階の理解を次で使う構成です
  • 数字をクリックする: 特に「計算過程ステップ表示」ではヤコビアンのセルをクリックすると、その数値の計算式と物理的な意味が表示されます
  • 演習で確かめる: 各段階に演習問題（解答つき）があります。特にStage 2の手計算チャレンジは、一度やっておくとツールの全表示の意味がわかるようになります
  • 疑ったら検算: すべての計算はMATPOWER公式解と照合したエンジンで動いており、「解の妥当性チェック」（電力収支）でいつでも検算できます
